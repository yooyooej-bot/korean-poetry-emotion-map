# 한국 현대시 15선 감정 분석 연구실 (Korean Poetry Emotion Map)

1920~40년대 한국 근현대 대표 시인 11인의 명시 15편을 **6대 정서 축(슬픔·애상, 그리움·향수, 희망·의지, 저항·울분, 고독·소외, 평온·서정)**으로 계량화하고, 행·연별 감성 흐름과 시어 가중치를 입체적으로 탐색할 수 있는 인터랙티브 웹 애플리케이션입니다.

- **배포 URL (GitHub Pages):** `https://[my-id].github.io/korean-poetry-emotion-map/`

---

## 1. 프로젝트 주요 기능

1. **개별 시 정밀 분석 (`개별 시 분석`)**
   - 15편의 시 원문, 시인 생몰연도 및 출처 정보, 연별 감성 궤적(꺾은선 그래프)과 6대 정서 분포(레이더 차트) 제공
   - 본문 내 핵심 시어 배지 클릭 시 정서 축 및 문맥적 분석 노트 확인
   - **키네틱 타이포그래피(숨결·바람결·먹빛 피어남·고요히)** 및 **AI 음성 낭독(Hugging Face `Supertonic-TTS-2-ONNX` 및 Web Speech API 폴백)** 연동
2. **15편 종합 비교 (`15편 종합 비교`)**
   - 15편 전체의 6대 정서 점수 히트맵/막대 차트 비교 및 정서 축별 대표작 필터링
3. **실시간 창작시 감성 판독 (`내 시 분석하기`)**
   - 사용자가 직접 시를 입력하면 한국어 감성 어휘 사전(188개 표제어)과 문맥 규칙을 결합하여 행별·전체 정서 비율과 지배 정서를 실시간 산출
4. **분석 기준 및 사전 검증 (`분석 기준·사전`)**
   - 6대 정서 축의 학술적 정의, 감성 어휘 사전 구성 원리, 검증 사례 확인

## 3. 6대 정서 축 정의

- **슬픔·애상 (`sorrow`)**: 이별, 상실, 시대의 비극 등으로 인해 마음속에 깊이 스며드는 비애와 서글픔의 정서
- **그리움·향수 (`longing`)**: 떠나간 임, 고향, 유년의 추억, 이상적 대상 등을 간절히 떠올리며 애틋하게 바라는 정서
- **희망·의지 (`hope`)**: 어두운 현실을 딛고 다가올 미래와 광복, 삶의 가치를 긍정하며 나아가려는 능동적 정서
- **저항·울분 (`resistance`)**: 식민지 억압과 부조리한 현실에 맞서 분노하거나 자기희생을 불사하며 항거하는 결연한 정서
- **고독·소외 (`solitude`)**: 세계나 타인, 심지어 자기 자신과도 단절되어 홀로 남겨진 실존적 외로움과 거리감의 정서
- **평온·서정 (`serenity`)**: 자연의 순수한 아름다움과 감각적 교감을 통해 얻는 고요하고 평화로운 마음의 정서

## 4. 디렉터리 구조 및 기술 스택

- **Frontend:** HTML5, Tailwind CSS (CDN), Vanilla JavaScript (ES Modules)
- **Visualization:** Chart.js 4.4.1 (레이더 차트, 연별 감성 궤적 차트, 코퍼스 비교 차트)
- **TTS & Motion:** `@huggingface/transformers` (`onnx-community/Supertonic-TTS-2-ONNX`), Web Speech API, HTML5 Canvas 3D 파티클 엔진

---

## 5. AI 도구 활용 내역

- **데이터 구조화 및 감성 어휘 사전 설계:** 한국 근현대시 15편의 연·행 단위 정서 점수와 188개 감성 어휘 사전(`js/data.js`)의 초기 가중치 부여 및 문맥 해석 초안 작성에 생성형 AI(Gemini)를 활용하였으며, 원문 표기와 시인 생몰연도는 위키문헌 및 공개 문학 아카이브를 기준으로 검수했습니다.
- **UI/UX 및 코드 모듈화:** 한국 전통 기와집·한지 테마 CSS(`css/style.css`), 키네틱 타이포그래피·음성 낭독 연동 엔진(`js/app.js`), 저장소 디렉터리 구조 분리에 AI 협업을 활용했습니다.
